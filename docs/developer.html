Kunhavigi aplikaĵon

Kiel paki aplikaĵon Dockan, por ke administrantoj konstruu kaj rulu ĝin loke kiel Linuksan servon.

En ĉi tiu paĝo

  1. Du roloj
  2. Ĉe la programisto
  3. Ĉe la administranto
  4. Starti kun la maŝino
  5. Lokaj bazaj bildoj
  6. Reto kaj pordoj

Du roloj

  • La programisto preparas la aplikaĵon: Dockanfile, dockan.yml, la kodon kaj README.
  • La administranto instalas Dockan sur la cela maŝino, konstruas la aplikaĵon loke kaj rulas ĝin loke.

Ĉe la programisto

Rekomendita strukturo:

myapp/
  Dockanfile
  dockan.yml
  README.md
  app.sh
  src/

Ekzemplo de Dockanfile:

FROM scratch
LABEL org.opencontainers.image.title=MyApp
COPY app.sh /app.sh
RUN chmod +x /app.sh
CMD ./app.sh

Ekzemplo de dockan.yml:

name: myapp
services:
  web:
    build: .
    image: myapp:latest
    ports:
      - 8080:8080
    volumes:
      - data:/data
    restart: always

Vi povas kunhavigi la aplikaĵon per Codeberg, GitLab, GitHub, arkivo .tar.gz, interna servilo aŭ eksterreta portilo.

Ĉe la administranto

Instali Dockan:

curl -fsSL https://raw.githubusercontent.com/Dockan-Conteneurisation-libre/Dockan/main/scripts/install.sh | sh

Akiri la aplikaĵon, konstrui kaj lanĉi ĝin:

tar -xzf myapp-dockan-v1.tar.gz
cd myapp
dockan build -t myapp:v1 .
dockan compose up

Kontroli la protokolojn:

dockan ps -a
dockan logs myapp-web

Uzu dockan ps -a --scope all, kiam kaj la uzanta kaj la sistema deponejoj povas enhavi ujojn.

Starti kun la maŝino

Aktivigi la aŭtomatan starton per systemd:

sudo dockan compose autostart -f /srv/myapp/dockan.yml --name myapp

Uzanta servo, sen sudo:

dockan compose autostart --user -f ~/myapp/dockan.yml --name myapp

Malaktivigi la aŭtomatan starton:

sudo dockan compose no-autostart -f /srv/myapp/dockan.yml --name myapp

Lokaj bazaj bildoj

Se la aplikaĵo bezonas kompletan bazon Ubuntu, Alpine aŭ Python, provizu arkivon de rootfs:

dockan base import ubuntu:local ./ubuntu-rootfs.tar.gz
dockan build -t myapp:v1 .

La Dockanfile tiam uzas la lokan bazon:

FROM ubuntu:local
COPY app.sh /app.sh
CMD ./app.sh

Reto kaj pordoj

Simpla reto:

dockan network create appnet
dockan run -d --name web --network appnet myapp:v1

Ponto kaj NAT kun publikigitaj pordoj:

dockan network create appnet --driver bridge --subnet 10.89.0.0/24 --gateway 10.89.0.1/24 --bridge dockan0
sudo dockan network enable appnet
sudo dockan run -d --name web --network appnet -p 8080:80 myapp:v1

Dockan mem disvastiĝas per siaj eldonoj; aplikaĵoj Dockan estas ordinaraj projektoj, kiujn oni povas libere kunhavigi.
