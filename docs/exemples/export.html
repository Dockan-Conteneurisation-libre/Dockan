Dokumentaro

Eksporti kaj importi

Dockan restas loka. Por kunhavigi aplikaĵon, kunhavigu la projektajn dosierojn, etikedu bildojn aŭ importu lokajn bazojn el dosieroj.

En ĉi tiu paĝo

  1. Konstruitaj bildoj
  2. Lokaj bazoj
  3. La malnova formato .dockan

Konstruitaj bildoj

Konstrui, listigi, aldoni etikedon kaj forigi bildon:

dockan build -t myapp:latest .
dockan images
dockan tag myapp:latest myapp:v1
dockan rmi myapp:v1

Lokaj bazoj

Importi bazon el dosierujo aŭ el arkivo, poste uzi ĝin:

dockan base import alpine:local ./alpine-rootfs
dockan base import ubuntu:local ./ubuntu-rootfs.tar.gz
FROM alpine:local
COPY app.sh /app.sh
CMD ./app.sh

La malnova formato .dockan

La malnova dosieruja formato ankoraŭ eksporteblas kaj importeblas:

dockan export myapp.dockan myapp.tar.gz
dockan import myapp.tar.gz myapp.dockan

Dockan malpakas importitajn arkivojn nur ene de la cela dosierujo: simbola ligilo en arkivo ne povas skribi ekster ĝi. Por novaj projektoj, preferu dockan build -t nomo:etikedo ..
