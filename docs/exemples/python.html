Ekzemplo en Python

Malgranda Python-aplikaĵo, konstruita kaj rulata loke per Dockan.

En ĉi tiu paĝo

  1. La dosieroj
  2. Konstrui kaj ruli
  3. Sen baza bildo Python

La dosieroj

myapp/
  Dockanfile
  app.py

app.py:

print("Hello from Python in Dockan")

Dockanfile:

FROM python:3.12
LABEL org.opencontainers.image.title=PythonExample
WORKDIR /app
COPY app.py ./app.py
CMD python3 app.py

Se neniu loka baza bildo python:3.12 ekzistas, Dockan uzas la komandon python3 de la maŝino por rapidaj konstruoj sen reto. Por importi lokan bazon:

dockan base import python:local ./python-rootfs

Konstrui kaj ruli

dockan build -t python-demo:latest .
dockan run python-demo:latest

Sen baza bildo Python

Se Python jam estas sur la maŝino kaj vi volas nur rapidan provon:

FROM scratch
LABEL org.opencontainers.image.title=PythonHostDemo
COPY app.py /app.py
CMD python3 app.py

Ĉi tiu versio dependas de la loka medio, do ĝi estas malpli portebla ol vera baza bildo python:local.
