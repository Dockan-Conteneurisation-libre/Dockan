Ĉu Dockan anstataŭas Docker?

Dockan celas esti loka kaj simpla alternativo al Docker por Linukso. Ĝi jam kovras la ĉefajn laborfluojn: konstrui, ruli, protokoloj, exec, volumoj, retoj, simpla compose kaj servoj de systemd.

Ĉu Dockan bezonas demonon?

Ne. Dockan ne rulas konstantan demonon kiel dockerd: ĉiu komando faras sian laboron rekte. Por aplikaĵoj, kiuj devas reveni post restarto, Dockan kreas denaskan servon de systemd:

sudo dockan compose autostart -f /srv/myapp/dockan.yml --name myapp

Ĉu Dockan funkcias sen root?

Jes, por la simplaj laborfluoj. Kelkaj altnivelaj funkcioj bezonas sudo:

  • ponto kaj NAT
  • retaj nomspacoj kaj veth
  • kelkaj muntadoj
  • sisteme larĝa instalo en /usr/local/bin

Ĉu Dockan elŝutas el Docker Hub?

Jes. Ekde v0.2.0, Dockan elŝutas OCI-bildojn el Docker Hub, GHCR aŭ Quay en pura Go, sen Docker kaj sen demono. Ĉiu tavolo estas kontrolata per sia haketaĵo, kaj vi povas fiksi bildon per ĝia haketaĵo.

dockan pull alpine:latest
dockan pull alpine@sha256:...
dockan run -d -p 8080:80 nginx:alpine

Lokaj bildoj (:local), lokaj dosierujaj registroj kaj rultempaj bazoj de la gastiganto funkcias sen reto kaj havas prioritaton.

Bildoj kun tavoloj zstd bezonas la ilon zstd sur la maŝino.

Kiel funkcias dependaĵoj?

Dockan povas eksplicite voki la pakaĵadministrilon de la maŝino: apt, dnf, apk, pacman aŭ zypper. Ĝi neniam instalas ion sekrete.

dockan deps check
sudo dockan deps install -y curl git

Ĉu mi povas uzi Dockerfile?

Jes, por simplaj Dockerfile. Dockan komprenas la oftajn instrukciojn; vidu la paĝon pri la formato.

Kie estas konservataj bildoj kaj volumoj?

Loke, en la deponejo de Dockan de la uzanto. Listigi la bildojn kaj krei volumon:

dockan images
dockan volume create data
dockan run -d --name app -v data:/data app:latest
dockan run -d --name app -v ./data:/data app:latest

Ĉu ponto kaj NAT disponeblas?

Jes, kun sudo:

dockan network create appnet --driver bridge --subnet 10.89.0.0/24 --gateway 10.89.0.1/24 --bridge dockan0
sudo dockan network enable appnet
sudo dockan run -d --name web --network appnet -p 8080:80 web:latest

Ĉu Dockan rulas grafikajn aplikaĵojn?

Jes, la simplajn: dockan run --gui app:latest. Tre kompleksaj aplikaĵoj povas bezoni manan agordon laŭ Wayland, X11, sono, GPU kaj permesoj.

Ĉu Dockan funkcias sur VPS aŭ Raspberry Pi?

Jes, se la maŝino uzas Linukson kaj havas la necesajn ilojn. La eldonoj celas Linukson amd64, arm64, armv7, 386 kaj riscv64.
