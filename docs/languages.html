Ĉiu programlingvo

Dockan rulas ĉiun Linuksan aplikaĵon, kiu havas tion, kion ĝi bezonas por starti: statikan binaraĵon, rultempon de la gastiganto aŭ lokan bazon.

En ĉi tiu paĝo

  2. Komenci projekton
  3. PHP, Node.js kaj Python

  5. Lokaj bazoj kaj rultempoj de la gastiganto

La regulo

Aplikaĵo ruliĝas, se unu el ĉi tiuj kondiĉoj veras:

  • ĝi estas statika Linuksa binaraĵo, kiu povas ruliĝi el FROM scratch
  • ĝia rultempo ekzistas sur la maŝino en la elektita izolada reĝimo
  • loka baza bildo enhavas la rultempon, ekzemple python:local, php:local aŭ node:local

Nomoj kiel php:8.3, node:20, python:3.12, openjdk:21 aŭ golang:1.22 funkcias ankaŭ sen Docker Hub, per la rultempo de via maŝino.

Komenci projekton

dockan new python my-python-app
dockan new node my-node-app
dockan new php my-php-app
dockan new go my-go-app
dockan new rust my-rust-app
dockan new java my-java-app
dockan new ruby my-ruby-app
dockan new binary my-binary-app

Poste:

cd my-python-app
dockan build -t my-python-app:latest .
dockan run -d --name my-python-app -p 8080:8000 my-python-app:latest

PHP, Node.js kaj Python

PHP

FROM php:8.3
WORKDIR /app
COPY . /app
EXPOSE 8000
CMD php -S 0.0.0.0:8000 -t public

Node.js

FROM node:20
WORKDIR /app
COPY . /app
EXPOSE 3000
CMD node server.js

Python

FROM python:3.12
WORKDIR /app
COPY . /app
EXPOSE 8000
CMD python3 app.py

Go kaj Rust

Por produktado, la plej fortika vojo ofte estas unue kompili Linuksan binaraĵon, poste uzi:

FROM scratch
COPY app /app
EXPOSE 8080
CMD ./app

Lokaj bazoj kaj rultempoj de la gastiganto

Por lokaj konstruoj, Dockan preferas lokajn bazojn kaj la rultempojn de via maŝino: konstruado restas rapida, antaŭvidebla kaj funkcias sen reto.

Se vi skribas FROM php:8.3 kaj neniu baza bildo php:8.3 ekzistas, Dockan serĉas php sur la maŝino. Se ĝi trovas ĝin, la konstruado daŭras; alie ĝi haltas kun klara eraro.

Instali mankantan rultempon, eksplicite:

dockan deps runtime php:8.3 --dry-run
sudo dockan deps runtime php:8.3 -y
sudo dockan deps runtime node:20 -y
sudo dockan deps runtime python:3.12 -y

Aŭ importi lokan rootfs aŭ arkivon:

dockan base runtime php:8.3 --from ./php83-rootfs
dockan base runtime node:20 --from ./node20-rootfs.tar.gz
dockan base import python:local ./python-rootfs.tar.gz

Dockan ne povas ruli lingvon sen ĝia rultempo: PHP bezonas PHP, Node bezonas Node, Java bezonas JRE aŭ JDK, Python bezonas Python.
